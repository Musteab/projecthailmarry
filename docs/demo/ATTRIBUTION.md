# Data attribution

- Road geometry, building footprints and facility records: © OpenStreetMap contributors, [ODbL](https://www.openstreetmap.org/copyright), accessed through the [Overpass API](https://overpass-api.de/). Display “© OpenStreetMap contributors” on maps using this pack.
- Elevation: [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/), Terrarium format, [Tilezen/Joerd source and attribution information](https://github.com/tilezen/joerd). Decoding: red × 256 + green + blue ÷ 256 − 32768 metres.
- Population allocation, capacities, unit placement, utility network and bridge vulnerability classes are synthetic exercise assumptions authored for BASTION, not official infrastructure or hazard assessments.
